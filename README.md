# OpenF4

OpenF4 is an open, [JSON](https://www.json.org/)-based specification for the standardized description of digital forms — including their data structure, validation logic, and workflow.

The goal of OpenF4 is to define forms in a platform-independent, machine-readable, and long-term interoperable way.

The key features are:

* Open source
* OpenF4 documents can be validated against the OpenF4 Document Schema
* Support for JSON Schema to describe the data structure
* Support for [CEL](https://cel.dev/) expressions to validate input
* Support for submission policies, such as scanned signatures, for submitting the online form
* Support for multilingualism
* ...and much more
