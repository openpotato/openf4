# Einführung

OpenF4 ist eine offene, [JSON](https://www.json.org/)-basierte Spezifikation zur standardisierten Beschreibung von digitalen Formularen – einschließlich ihrer Datenstruktur, Validierungslogik und Workflow.

Ziel von OpenF4 ist es, Formulare plattformunabhängig, maschinenlesbar und langfristig interoperabel zu definieren.

Die wesentlichen Eigenschaften sind:

+ Open Source
+ OpenF4-Dokumente können gegen das OpenF4 Document Schema validiert werden.
+ Unterstützung von JSON-Schema als zum beschreibung der Datenstruktur
+ Unterstützung von [CEL](https://cel.dev/)-Ausdrücken zur Validierung von Eingaben
+ Unterstützung von Submission-Policies (z.B. eingescannte Unterschrift) für das Absenden des Online-Formulars
+ Unterstützung von Mehrsprachigkeit
+ ...und noch einiges mehr

Der Namensbestandteil F4 leitet sich aus dem englischen Begriff für Formular - *Form* - ab: Die Zahl 4 repräsentiert die Anzahl der Zeichen nach dem F.

## Aktueller Status

OpenF4 befindet sich noch in der Entwicklung. Wir planen eine Veröffentlichung im 4. Quartal 2026.
