# Community

OpenF4 ist ein Open Source-Projekt. 

Wie freuen uns über Feedback jeglicher Art, egal ob positiv oder negativ:

+ Ein Frage oder Meldung im [GitHub Issue Tracker](https://github.com/openpotato/openf4/issues) erstellen.
+ Eine Diskussion unter [GitHub Discussions](https://github.com/openpotato/openf4/discussions) starten.
+ Einen [Pull-Request](https://github.com/openpotato/openf4/pulls) initiieren.
